Privacy Policy

MFX Drive Cache is a private, owner-operated research application, not a public service. This policy describes how its Google OAuth integration accesses and handles Google user data.

Google information accessed

When the owner explicitly authorizes the application, it requests the Google Drive drive.file OAuth scope. This permits it to create new Drive files and to view or modify files authorized for use with the application. It does not request full Google Drive access, Gmail messages, Contacts, or Calendar data.

Purpose and use

The application creates its own Drive folders and JSON files for synthetic connectivity checks, cache integrity tests, and permitted private research data. It reads back file content and metadata to validate saved data and consistency. The app does not use Google Drive data for advertising, profiling, or selling user information.

Storage and service providers

Application-managed JSON files are stored in the owner's Google Drive account. GitHub Actions runs the application's cloud code and stores OAuth client credentials and refresh tokens in repository Actions Secrets. Diagnostic workflow logs may contain non-secret file identifiers, checksums, status messages, and execution details. Google and GitHub process data as infrastructure providers under their own terms and policies. This informational website has no sign-in form, analytics script, or advertising tracker.

Sharing

The app does not sell personal data or intentionally make the owner's application-managed Drive files public. Data is processed by Google Drive and GitHub Actions as necessary to provide the private functionality. MFX does not provide a public data-sharing service.

Retention and deletion

Files remain in the owner's Google Drive until the owner deletes them. The owner can revoke this app's Google permissions from their Google Account's third-party connection settings, remove its GitHub Actions Secrets, and delete the application-managed Drive files. Revoking access stops future authorized access but does not automatically delete previously stored files or prior workflow logs.

Security

OAuth tokens are not placed on this public website or committed to source control. Application access uses HTTPS and scoped Google permissions. No internet-connected service can promise absolute security.

Changes and contact

This policy may be updated as the application's behavior changes. Material changes will be reflected on this page. To contact the project maintainer, visit the GitHub repository issue tracker. Do not publish credentials or private Drive data in issues.
