Private research application

Secure, limited-access Google Drive storage for MFX.

MFX Drive Cache is an owner-operated tool supporting a private Forex research and engineering project. GitHub Actions uses Google OAuth to manage application-specific files in the owner's Google Drive account.

Limited Drive permission

The application requests only the Google Drive drive.file permission, used to create, read, and update files that the application is allowed to access. It does not request general access to all Drive files.

Private storage

Application-managed files reside within the owner's personal Google Drive. Authentication is managed by Google OAuth, with credentials stored as GitHub Actions Secrets.

Research, not brokerage

Cache and test data support research and technical validation. This app does not place broker orders or provide a public trading service.

Why Google access is requested

The app needs permission to create and verify application-owned storage folders, write and update JSON cache files, and read those files back to check integrity. Access is initiated by the account owner and may be revoked at any time.

For details on data handling, see our Privacy Policy. This website is informational; it does not provide an OAuth sign-in form or collect credentials.
