Privacy Policy

MST Cloud Drive is a private, owner-operated engineering and research utility, not a public trading service. This policy describes the app's intended limited use of Google user data. The OAuth and Google Drive GitHub Actions integration is staged, and production market-data automation is not yet active.

Google information accessed

When the account owner explicitly authorizes the integration, the application requests Google Drive's drive.file scope. It can create new files and access specific files created by, opened with, or selected for the app as permitted by Google. It does not request general read access to all Google Drive files or access to Gmail, Contacts, or Calendar.

Purpose and data use

Owner-authorized Drive files may include application-created folders, synthetic connectivity and integrity test JSON files, and subsequently approved private research cache data. The app reads file content or metadata when necessary to verify integrity and consistency. It does not use Google user data for advertising, profiling, or selling personal information. Existing owner-created Watchlist Sheets are not automatically accessible to the OAuth app.

Storage, service providers, and access

Data that the owner separately approves for persistence resides in the owner's own Google Drive. GitHub Actions runs the cloud workflows and stores any configured OAuth Client Secret and Refresh Token in private repository Actions Secrets. Limited workflow diagnostics may record non-secret status, checksums, and sanitized audit results; the app is designed not to publish access tokens or personal research data to logs. Google and GitHub provide supporting infrastructure under their respective terms.

Sharing and disclosure

The application does not intentionally make private Drive data public, sell user data, or provide an advertising data-sharing service. Google Drive and GitHub process information as necessary to operate these authorized workflows. No broad public sharing permission is requested by this website.

Retention, withdrawal, and deletion

Files created by the app remain in the owner's Google Drive until the owner removes them or a separately approved retention policy applies. The owner may revoke Google's third-party application permission, remove GitHub Actions Secrets, and delete application-managed folders and files. Revoking OAuth access stops future authorized requests but does not automatically delete preexisting files or historical diagnostic logs.

Website privacy and security

This public informational website has no sign-in form, OAuth callback handler, analytics trackers, or advertising scripts. No OAuth token, private Drive file ID, financial account credential, or market research dataset should be submitted through this site. Google OAuth uses HTTPS. No online service can guarantee absolute security.

Changes and contact

This policy will be updated if data handling changes. To contact the developer, use the MST GitHub issue tracker; never post credentials, tokens, or private files in a public issue.
