Private, owner-operated research application

Limited-access cloud storage for MST research.

MST Cloud Drive supports a separate cloud-only engineering project for Vietnamese stock-market research. Its planned Google OAuth connection allows owner-approved GitHub Actions workflows to manage specific application-authorized files in the owner's Google Drive, while keeping market-source and trading permissions separately controlled.

Limited file permissions

MST requests the Google Drive drive.file scope, which allows it to manage files created by or explicitly selected for the app. The app does not request unrestricted access to every file in your Drive.

Owner-controlled storage

After separate authorization, app-specific storage will be located in the owner's Google Drive. GitHub Actions will hold OAuth credentials only in private repository Secrets. This website does not request or accept passwords, access tokens, or market data.

Research, not execution

Any future permitted cache data is intended for technical analysis and integrity testing. MST is not a public brokerage, does not place trades, and does not provide a public financial advice service.

Why MST asks for Google Drive access

The planned integration can create application-managed storage folders, persist owner-authorized research data where separately permitted, and read back specific files for integrity verification. Existing private Google Sheets and Drive folders do not automatically become accessible under drive.file.

OAuth activation, scheduled collection, and any third-party market-data caching remain subject to separate configuration, approvals, and testing. Read our Privacy Policy and Terms of Use. This site is informational only and does not handle Google OAuth redirects.
